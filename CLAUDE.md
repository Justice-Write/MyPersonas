# Claude / Cowork entry point

Read `status-handoff.md` in full before acting, then read `AGENTS.md` and the instructions nearest the files you will touch. `status-handoff.md` is the shared current-state and work-claim record; `AGENTS.md` holds durable product and safety boundaries.

Do not infer that a local build is deployed, that a package is installed, that a provider action was sent, or that a model supplied human approval. Preserve dirty owner checkouts and private `outputs/` material. Use a clean focused worktree for repository changes, record exact tests and external evidence, and keep build, commit, push, merge, deploy, install and acceptance as separate states.
