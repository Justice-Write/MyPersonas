Browser app install check

  1. Open the reviewed live https://mypersonas.online/ release in Chrome on Android or Safari on iPhone/iPad.
  2. On Android, use Install app when the browser offers it, or open the browser menu and choose Install app or Add to Home screen.
  3. On iPhone or iPad, open Share and choose Add to Home Screen.
  4. After installation, verify the app opens standalone and fetches signed-in data fresh. An icon alone is not proof that the current release is installed.

The install helper never posts, requests notification permission, or subscribes to push. Push remains a separate, unimplemented release phase.
